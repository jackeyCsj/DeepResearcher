Article history:                                     In this paper, we propose a robust local descriptor for face recognition. It consists of two components, one based
Received 25 October 2015                             on a shearlet-decomposition and the other on local binary pattern (LBP). Shearlets can completely analyze the
Received in revised form 28 March 2017               singular structures of piecewise smooth images, which is useful since singularities and irregular structures
Accepted 13 May 2017                                 carry useful information in an underlying image. Furthermore, LBP is effective for describing the edges extracted
Available online 31 May 2017                         by shearlets even when the images contain high level of noise. Experimental results using the Face Recognition
                                                     Grand Challenge dataset show that the proposed local descriptor significantly outperforms many widely used
Keywords:                                            features (e.g., Gabor and deep learning-based features) when the images are corrupted by random noise, demon-
Robust local feature                                 strating robustness to noise. In addition, experimental results show promising results for two challenging
Remote face recognition                              datasets which have poor image quality, i.e., a remote face dataset and the Point and Shoot Face Recognition
                                                     Challenge dataset.

    When we use the shearlet plus LBP for face recognition, we divide
each face into patches as done in [1,58]. One example is shown in
Fig. 7. Unlike [1,58], we build one classifier for each patch. Specifically,
for each patch pi, where i = 1, 2...20, we compute its shearlet transfor-
mation ~ j;l;k as in Eq. (7) and then LBP feature as in Eq. (8), i.e., fLBP(~ j;l;k).
The window to compute LBP is 3 × 3 neighbors as in Fig. 3 and we then
build the histogram for each patch. Thus we have 256 bins for each ~ j;l;k.
We then use the PCA to reduce the dimensionality of the feature
fLBP(~ j;l;k). We keep 98% energy following [4]. After that, we get  =
fPCA(fLBP(~ j;l;k)). For the resulting features , we use Linear Discriminant
Analysis (LDA) [18] to perform face recognition. Note that we did not
concatenate the LBP features of each patch into one long histogram
and both PCA and LDA are applied to per patch histogram here.
